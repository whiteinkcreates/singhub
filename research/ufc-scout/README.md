## Why a Paramount+ subscription is not a bar license

Consumers have all numbered cards and Fight Nights in Paramount+ with no PPV upsell. But [Joe Hand Promotions' official commercial explanation](https://www.joehandpromotions.com/inside-the-new-ufc-event-model-for-commercial-establishments/) and [UFC commercial-bundle announcement](https://www.joehandpromotions.com/ufc-and-joe-hand-promotions-team-up-to-offerpackage-of-live-combat-sports-eventsto-bars-and-restaurants/) show bars can still purchase individual numbered events or an all-event commercial subscription. A bar showing one UFC event therefore **cannot** be assumed to show all the rest.

## SCOUT-like operating procedure

1. Discover sources: UFC bar locator, venue official website/calendar, venue Instagram/Facebook posts/events, booking pages, reputable secondary schedules as leads only.
2. Match **normalized name + exact address**, resolve aliases and location-specific franchises, and compare against latest San Diego canonical + Backyard research.
3. Record evidence date, source URL, first/third-party tier, named UFC fight if explicitly advertised, local start time, venue opening-hours compatibility and karaoke signal separately.
4. Use stable candidate keys from the TSV. Each new source **enriches an existing venue**, rather than spawning duplicates.
5. Venue classifications: `locator_snapshot_only`, `current_venue_site_ufc_claim`, `dated_screening_verified`, `historical_ufc`, `contradicted_closed`, `needs_review`.
6. Prioritize existing canonical venue changes for Backyard UFC, and new karaoke crossover candidates for Corey approval. Never auto-create canonical venues.
7. **Never** turn a generic UFC programming claim into a specific UFC event occurrence. Fight-event publish requires venue+fight+date source and an authenticated app write.
8. For repeat runs, compare against this baseline and notify only for supported changes. The existing daily **SingHUB UFC Venue Watch** can act as a research monitor, but it **does not currently write to the Backyard page**.
